# Data Folder

This project uses the public Our World in Data COVID-19 dataset:

- Source page: https://ourworldindata.org/coronavirus
- Direct CSV used by the code: `https://covid.ourworldindata.org/data/owid-covid-data.csv`

The raw CSV is not committed because it is large and updated regularly.

- `data/raw/` stores the downloaded source CSV after you run `main.py`
- `data/processed/` stores the cleaned and feature-engineered dataset
